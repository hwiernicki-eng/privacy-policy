# Maquettes Claude Design — direction B · Cockpit (clair)

Sources des artboards du canevas Claude Design « Carnet d'entretien — interfaces ». Format `.dc.html` : HTML statique + styles inline, rendu par le runtime Claude Design (`support.js`, non fourni) ; **ne pas les servir tels quels**. Les lire comme spécification visuelle : structure, espacements, couleurs, tailles de police.

| Fichier | Écran | Taille |
|---|---|---|
| `B-Accueil.dc.html` | Tableau de bord mobile (sélecteur de véhicule, témoins, jauges) | 390 × 844 |
| `B-Vehicule.dc.html` | Fiche véhicule mobile (compteur en arc, échéances au km, journal) | 390 × 844 |
| `B-Bord-Desktop.dc.html` | Tableau de bord desktop (flotte, À faire, Ensuite) | fluide, 1440 de référence |
| `B-Bienvenue.dc.html` | Premier lancement, étape 3 | 390 × 844 |

En cas d'écart avec `docs/prototype.html`, le prototype fait foi pour le comportement, les maquettes pour le rendu mobile. Les jetons de couleur sont ceux de `docs/DESIGN.md` (valeurs en dur dans les maquettes).
